# 界面设计与验收

应用名称：短信转邮件。中文 Material 3 工具型界面，主色 #245DD8，浅背景 #F4F6FA，白色卡片；深色使用深蓝灰背景。主要卡片 18–24dp 圆角，页面 20dp 留白。字号采用 Material 语义层级，触控目标使用标准 Button / Switch / IconButton 尺寸。

四个底部入口：

1. 首页：状态主卡 + 总开关；今日已提交 / 待处理统计；未配置引导；最近记录。
2. 规则：默认去向卡片；规则名、正则、收件人、启用开关；悬浮新增按钮；编辑内含样例测试。
3. 记录：时间、来源、匹配规则及逐收件人状态数量；详情折叠正文，提供独立失败重试。
4. 设置：邮箱与收件人、运行权限、数据与隐私三组；邮箱与收件人组包含联系人管理、默认收件人选择和测试邮件选择。

辅助页面使用可滚动弹窗，包括发件邮箱、联系人管理、联系人编辑、默认收件人选择、测试邮件选择、规则编辑、规则收件人选择、短信详情和删除确认。联系人选择支持搜索、多选和快速新增；规则编辑提供所有／验证码／金额／自定义四种快速配置，切换到自定义后保留可编辑正则。设置页增加短信接收诊断，只展示广播时间、片段数、正文长度和解析状态，不展示诊断正文。表单验证失败保留输入，规则打开联系人选择器后保留草稿。耗时操作禁用重复提交并展示进度，异步错误单独提示。

验收需覆盖：空数据、已配置、运行中、暂停、失败、不确定；浅色、深色、大字体；系统权限拒绝后返回；长短信和长邮箱内容。实际模拟器截图将放入 `docs/screenshots/`，在截图产生前不视为视觉验收通过。
