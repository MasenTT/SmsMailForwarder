# 短信转邮件

中文 Android 工具，支持短信正文正则分流、联系人选择、多人收件、无匹配时默认转发、断网队列和逐收件人发送记录。

功能截图、使用流程和架构说明见 [图文介绍](docs/PROJECT-GUIDE.md)。

## 首次使用

1. 安装 APK，打开应用。
2. 在「设置 → 发件邮箱」选择 QQ、163 或填写其他 SMTP 服务器。输入邮箱和 **SMTP 授权码**。
3. 进入「设置 → 联系人管理」，维护姓名、邮箱和备注；联系人只保存在本机，不需要通讯录权限。
4. 在「默认收件人」中勾选一个或多个联系人；规则收件人和测试邮件也可直接从联系人选择。
5. 主动发送一封测试邮件，核实收件箱及垃圾邮件箱。
6. 授予短信接收权限，并在系统应用设置中允许后台运行。重启后需完成首次解锁；不同厂商的自启动入口不同。
7. 按需新增转发规则。可快速选择“所有、验证码、金额”，或切换到“自定义”填写 RE2 正则；样例短信测试不发送邮件，只展示匹配结果。
8. 在首页开启转发；从另一台手机发送短信，检查记录及邮箱。
9. 如果短信没有进入记录，打开「设置 → 短信接收诊断 → 复制诊断信息」，可把脱敏结果发给开发者定位系统广播、权限状态或应用开关问题。

QQ、163 通常需要在网页版邮箱开启 SMTP 并生成授权码，以邮箱提供商显示的设置为准。SSL/TLS 常用端口 465；STARTTLS 常用端口 587。本应用强制加密连接和服务器身份校验，不支持明文 SMTP。

## 联系人与规则快速配置

联系人用于复用收件邮箱，编辑联系人邮箱只影响后续新收到的短信；已经排队或历史记录中的任务保留接收时的邮箱地址。被规则或默认收件人引用的联系人需要先解除引用才能删除。

规则编辑页提供四种入口：

- **所有**：匹配所有已经接收的短信。
- **验证码**：匹配验证码、校验码、动态口令、一次性密码、OTP 及常见英文提示。
- **金额**：匹配带元、人民币、¥、￥、RMB 或 CNY 的金额表达式。
- **自定义**：直接填写 RE2 正则；预设可以一键转为自定义继续修改。

## 分流例子

- `告警|故障` → 运维邮箱、负责人邮箱。
- `账单|余额` → 财务邮箱。
- `(?s)^通知.*完成$` → 匹配包含换行的整段通知。

规则为 RE2 语法，默认包含匹配；不支持环视、反向引用。所有启用规则都参与匹配并合并收件人。没有任何规则命中时才用默认收件人。邮箱去重忽略大小写。

## 发送状态

- 等待发送：等待网络、调度或重试。关闭总开关会暂停未发送任务。
- 发送中：正在联系邮件服务器。
- 已提交：邮件服务器接受了邮件，不能据此断言已进入收件箱。
- 配置待修正：修正并保存发件设置后恢复。
- 发送失败：永久错误或已达到 5 次自动尝试，可在详情手动重试。
- 结果不确定：提交期间中断，邮件可能已送达。核实邮箱后再手动重试，可能重复。

长短信会合并为正文；双卡信息以系统广播可提供的信息为准。来源号码及正文加密保存在本机，授权码由 Android Keystore 保护。不会上传至开发者服务器。收件邮箱和规则名称作为本机元数据保存。完成记录默认保留 7 天；未完成任务不会自动删除。

## 兼容范围

最低 Android 8.0，当前编译 API 37、目标 API 36。验证码接收受系统额外权限限制，不能保证全部设备可获取；带 SMS Retriever 标识的短信可能只发送给目标应用，Android 17 对 WebOTP/OTP 的保护对所有目标版本生效，目标 API 37 及以上还会扩大到标准短信，因此目标 API 36 不能绕过验证码保护。处理普通新 SMS 及系统交付且可解析的数据短信，不处理历史短信、彩信、RCS 或 WAP Push。强行停止、未授权或系统拦截期间收到的短信无法保证获取。设置页的“短信接收诊断”可区分系统未发广播、广播解析失败和后续发送失败；“复制诊断信息”还会显示 Android API、系统构建、安全补丁、AppOps、敏感短信能力、默认短信角色、安装来源和省电状态，但不包含短信正文、号码、邮箱或授权码。卸载会删除本地配置、记录和密钥。

具体已验证设备、测试证据及未完成事项见 `docs/TEST-REPORT.md` 和 Downloads 下的 `SmsMailForwarder-PLAN.md`。

当前测试版为 0.2.1，数据库会将旧版规则收件邮箱和默认邮箱迁移为联系人并保留排队任务。真机逐项验证表见 [设备验收清单](docs/DEVICE-ACCEPTANCE.md)。

连接一台已开启 USB 调试的 Android 手机后，可运行 `scripts/collect-device-debug.sh` 生成不含短信正文的设备诊断文件，便于定位系统广播、后台限制和邮件队列问题。

实际界面截图见 [界面预览](docs/SCREENSHOTS.md)。运行 `scripts/build-local.sh` 前，确认 `JAVA_HOME` 指向 JDK 21（若仍指向 JDK 8，构建会失败）。

## 开发构建

安装 JDK 21 和 Android SDK（API 37.0、Build Tools 36.0.0）。在本机 `local.properties` 中填写 SDK 路径，勿将此文件提交。

```sh
./gradlew :core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
./gradlew :app:connectedDebugAndroidTest
```

Gradle Wrapper 版本为 9.3.1。首次构建需要网络下载依赖。仪器测试需要 Android 模拟器或已授权的测试设备；测试使用伪邮件网关，不会给外部邮箱发送邮件。

`core` 包含纯逻辑及覆盖率报告，`app` 包含 Compose UI、Room、Keystore、短信广播与 WorkManager。详细结构见 `docs/ARCHITECTURE.md`。

公开发布前需要正式签名、目标商店政策核实、隐私政策及相应审核材料；调试签名 APK 不代表正式上架版本。
